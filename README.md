# Contact Form Project

## Task 2 - Contact Form with MySQL

### Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS

### Features
- Contact form with Name, Email, and Message fields
- Stores submitted data in MySQL database
- Uses Spring Data JPA
- REST API to retrieve all contacts

### API Endpoint
GET /contacts

### Sample JSON Response

[
  {
    "id": 1,
    "name": "Rukshana",
    "email": "rukshana@gmail.com",
    "message": "Hello"
  }
]
